# Brand assets

Logo files for Seralith. They are generated by
[`scripts/brand/generate.py`](../scripts/brand/generate.py); edit the generator,
not the files.

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/brand/requirements.txt
npm pack @fontsource/cinzel && tar -xzf fontsource-cinzel-*.tgz
.venv/bin/python -B scripts/brand/generate.py --font package/files/cinzel-latin-700-normal.woff
```
